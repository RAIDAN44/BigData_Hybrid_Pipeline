CORE ARCHITECTURE

ما الذي يميز المشروع؟

Raw-first

يُحفظ كل سجل كما وصل قبل أي تنظيف، مما يمنع ضياع البيانات ويضمن قابلية التتبع.

Bounded Memory

المعالجة الكبيرة لا تحمل 30M سجل في الذاكرة مرة واحدة؛ بل تستخدم دفعات وقراءات محدودة.

Upsert / Idempotency

إعادة التشغيل لا تنشئ Business Records نهائية مكررة؛ Insert أو Update أو Unchanged فقط.

Evidence Read-only

BASE VALIDATION CONTRACT

لماذا ظهر Valid بهذا العدد؟

Valid هو السجل الذي دخل بدون أي Error وبدون أي Correction. لذلك، عند استخدام نفس العينة ونفس الـBase Schema ونفس قواعد التحقق الأساسية، يجب أن تكون مجموعة السجلات Valid متطابقة.

Corrected وQuarantine قد يختلفان قليلًا بسبب اختلاف تغطية التصحيحات الحتمية الآمنة، وليس لأن تعريف Valid يتغير.
